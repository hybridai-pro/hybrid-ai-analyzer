# HYBRID AI Stock Analyzer

Analisi fondamentale algoritmica a 360° powered by Hybrid AI.

## Setup

1. Clona il repo
2. `npm install`
3. Crea `.env.local` con `ANTHROPIC_API_KEY=sk-ant-...`
4. `npm run dev`

## Deploy Vercel

Aggiungi la variabile d'ambiente `ANTHROPIC_API_KEY` nelle impostazioni del progetto Vercel.
